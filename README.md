## Body-Script

Body Script is a place for users to track their moods and period. 
Besides that, it allows users to connect their own smart devides, so users can have tracking history to review how their period impacts feelings and other symptons.

## Features

- User can enter their moods, symptoms.
- User can connect with their smart devices as Apple Watch and Oura Ring.


## Built with

- Node.js and Express
- MongoDB with Mongoose
- EJS templates
- Plain JavaScript and CSS
- REST API 
- Passport authentication

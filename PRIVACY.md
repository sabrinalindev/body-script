## Privacy Policy — CycleSync

**Last updated: November 6, 2026**

Body Script is a menstrual cycle tracking application currently under development for educational and portfolio purposes.

The application is designed to allow users to manually record menstrual cycles, symptoms, and moods, with optional integration of Oura Ring and Apple Health data.

Health data will only be accessed with the user's authorization. The application is intended to use this information for personal tracking and visualization.

During development, the application is not intended for public use or the collection of other users' real health information.

Before any public release, this policy will be updated to explain data collection, storage, security, retention, deletion, and user rights.

For privacy questions, contact the application developer through the project's GitHub repository.
